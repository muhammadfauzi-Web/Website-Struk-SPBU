Fitur Unggulan

Sistem ini dirancang khusus untuk mempermudah operasional kasir di pulau pompa Anda.

Kalkulasi Otomatis

Nominal pembelian langsung dikonversi ke liter secara presisi, kembalian ikut terhitung tanpa kalkulator terpisah.

Rincian Subsidi

Porsi harga non-subsidi dan subsidi pemerintah untuk BBM penugasan dipisah secara otomatis dan dicetak di nota.

Printer Bluetooth

Terhubung lancar nirkabel ke printer thermal 58/80 mm, lengkap dengan format standar dan logo di kepala struk.

Kustomisasi Bebas

Ubah Kode SPBU, Nama SPBU, Alamat, dan setelan harga per liter kapan saja langsung dari menu pengaturan aplikasi.

Cara Pemasangan di Android

Ikuti 3 langkah mudah berikut untuk mulai menggunakan aplikasi di perangkat kasir Anda.

  1. Unduh Berkas APK

    Tekan tombol "Unduh Aplikasi" di atas. File APK akan tersimpan di dalam folder Download pada perangkat Android Anda.

  2. Izinkan Sumber Tidak Dikenal

    Buka file APK tersebut. Jika muncul peringatan, masuk ke Setelan dan aktifkan "Izinkan dari sumber ini" untuk aplikasi File Manager/Browser Anda.

  3. Hubungkan Printer

    Setelah terinstal, buka aplikasi. Nyalakan Bluetooth perangkat Anda, pasangkan (pairing) dengan printer thermal, lalu tekan tombol 🔌 Hubungkan Printer di aplikasi.

Info Pembaruan: Aplikasi akan secara otomatis memeriksa versi terbaru dari halaman ini. Jika ada pembaruan, notifikasi akan mengarahkan Anda ke halaman ini.
